    🛠️ Tools

    Templates

    Add, edit, or duplicate the message templates used by the Admin Assistant. Variables like [CLIENT_NAME] are automatically filled in when a message is generated.

    Edit Template

    Common variables: [CLIENT_NAME] [PET_NAME] [BREED] [ZIP] [SERVICE] [PRICE] [LUXURY_BATH_PRICE] [FULL_GROOM_PRICE] [DATE] [TIME] [GROOMER] [PHONE] [EMAIL] [ADDRESS] [ADMIN_NAME] [MISSING_FIELDS_LIST] [ADDON] [FREQUENCY] [DAY]. Variables that come straight from a form field (like [DATE] or [ADDON]) stay as [LIKE_THIS] in the output if left blank, so it's obvious what still needs filling in by hand. [MISSING_FIELDS_LIST] is computed automatically and always fills in.

    Activity Log

    Nothing gets logged automatically. Click "Add to Activity Log" next to a generated message (with an optional note) to save it here — date, ZIP, client, your note, and whichever Client & Request Details fields are filled in. Good for a daily report to the owners.
